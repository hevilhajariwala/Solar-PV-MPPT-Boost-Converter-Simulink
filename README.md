# Solar PV MPPT and Boost Converter using MATLAB/Simulink

## Overview

This project implements a Solar Photovoltaic (PV) power conversion system
using MATLAB/Simulink.

The system consists of a Solar PV plant, voltage and current measurement,
a DC-DC boost converter, MPPT control, DC-link voltage control, current
control, PWM generation, and a variable load.

The main objective is to extract power from the PV source and regulate the
DC bus voltage using suitable control techniques.

## System Architecture

The overall power flow is:

Solar PV Plant
        ↓
Voltage & Current Measurement
        ↓
DC-DC Boost Converter
        ↓
DC Bus
        ↓
Variable Load

The boost converter is controlled through a PWM signal generated by the
control system.

## Control Modes

The model provides two operating modes.

### 1. MPPT Mode

The Maximum Power Point Tracking (MPPT) controller adjusts the boost
converter control signal so that the PV system operates near its
maximum power point.

The MPPT mode is selected through the PV Mode control.

### 2. Constant Voltage Mode

In Constant Voltage mode, the DC bus voltage is regulated toward a
reference value.

The reference voltage used in the model is:

Vref = 375 V

The voltage error is calculated as:

text
e_v = Vref - Vdc

## Boost Converter

A DC-DC boost converter is used to increase the PV voltage to the required DC bus voltage.

It consists of:
- Inductor
- Switch
- Diode
- DC-link capacitor

The converter is controlled using PWM, and its duty cycle is adjusted by the control system.

For an ideal boost converter:

**Vout = Vin / (1 - D)**
